# Каталог неликвидов - Django Приложение

## Обзор проекта

Это Django-приложение предназначено для управления каталогом неликвидной продукции на предприятии. Приложение позволяет отслеживать, документировать и управлять неликвидами по различным подразделениям предприятия.

### Основные функции:
- Управление подразделениями предприятия
- Создание и редактирование записей о неликвидах
- Загрузка и обработка изображений товаров
- Ролевая система доступа (Viewer, Editor, Subdivision_Admin, Super_Admin)
- Поиск по каталогу
- Управление статусами и состоянием товаров

### Технологии:
- Django 6.0.1
- PostgreSQL (через psycopg2-binary)
- Redis (для Celery)
- Celery (для фоновых задач)
- Pillow (для обработки изображений)

## Модели данных

### Subdivision (Подразделение)
- `name` - Название подразделения
- `code` - Уникальный код подразделения
- `manager` - Руководитель подразделения

### Product (Продукт/Неликвид)
- `code` - Уникальный код продукции в рамках подразделения
- `name` - Наименование
- `description` - Описание
- `characteristics` - Характеристики в формате JSON
- `subdivision` - Подразделение, к которому относится
- `status` - Статус (доступен, зарезервирован, использован, списано)
- `condition` - Состояние (новое, б/у, неисправное, на запчасти)
- `quantity` - Количество
- `location` - Место хранения

### ProductImage (Изображение продукта)
- `product` - Связь с продуктом
- `image` - Оригинальное изображение
- `thumbnail` - Миниатюра
- `is_main` - Основное изображение

### Profile (Профиль пользователя)
- `user` - Связь с пользователем Django
- `subdivision` - Подразделение, к которому привязан пользователь
- `phone`, `position` - Дополнительная информация

## Система прав доступа

Приложение реализует ролевую систему доступа с четырьмя уровнями:

1. **Viewer** - Только просмотр
2. **Editor** - Просмотр и редактирование в своем подразделении
3. **Subdivision_Admin** - Просмотр, редактирование и удаление в своем подразделении
4. **Super_Admin** - Полный доступ ко всем подразделениям

Права проверяются через методы в модели Profile.

### База данных
- SQLite (по умолчанию)

- Специальная конфигурация для Windows

## Запуск проекта

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Настройка базы данных
```bash
python manage.py migrate
```

### Создание суперпользователя
```bash
python manage.py createsuperuser
```

### Запуск сервера разработки
```bash
python manage.py runserver
```

### Запуск Celery (для обработки изображений)
```bash
celery -A config worker --pool=solo -l info
```

### Запуск планировщика задач (опционально)
```bash
celery -A config beat -l info
```

## Разработка

### Структура URL
- `/` - Главная страница (список подразделений)
- `/login/` - Страница входа
- `/logout/` - Выход из системы
- `/{subdivision_code}/` - Список продуктов в подразделении
- `/product/{product_id}/in/{subdivision_code}/` - Детали продукта
- `/create/{subdivision_code}/` - Создание продукта
- `/search/` - Поиск по каталогу
- `/profile/` - Профиль пользователя
